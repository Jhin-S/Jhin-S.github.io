## 1. Tensor Shapes & Batch Dimensions (텐서 모양 및 배치 차원)

**[KR]**
* **모양 확인 (Checking Shapes):** `distances.shape` $\rightarrow$ `torch.Size([6, 1])`
  * $6 = $ 배치 크기 (Batch Size): 전체 배달 샘플 개수
  * $1 = $ 특성 크기 (Feature Size): 샘플당 입력 특성 개수
* **배치 차원 규칙 (The Batch Dimension Rule):**
  * 신경망 모델은 항상 첫 번째 차원을 배치 크기로 인식합니다.
  * 모델은 배치 크기가 6개든 600개든 상관없이 동일한 메커니즘으로 처리합니다.
  * **특성 불일치 (Feature Mismatch):** 1개 특성용 모델에 3개 특성(거리, 시간, 날씨) 데이터를 입력하면 `Shape Mismatch` 오류가 발생합니다.

**[EN]**
* **Checking Shapes:** `distances.shape` $\rightarrow$ `torch.Size([6, 1])`
  * $6 = $ Batch Size (number of delivery samples)
  * $1 = $ Feature Size (distance per sample)
* **The Batch Dimension Rule:**
  * Neural network models expect the first dimension to be the batch size.
  * Models process inputs regardless of batch size (6 or 600 samples operate identically).
  * **Feature Mismatch:** Passing 3 input features (e.g., distance, hour, weather) into a 1-feature model triggers a Shape Mismatch Error.

## 2. Data Types & Type Promotion (데이터 타입 및 타입 프로모션)

**[KR]**
* **기본 데이터 타입 (Default Dtypes):**
  * 정수 (Integers): `torch.int64` (Long Tensor)
  * 실수 (Decimals): `torch.float32` (Float Tensor)
* **딥러닝 최적 타입 (Best Practice for Deep Learning):** `torch.float32` 사용 (GPU/하드웨어 연산 시 표준이며 가장 효율적)
* **변환 방법 (Convert using):** `torch.tensor(data, dtype=torch.float32)` 또는 `tensor.float()`
* **타입 프로모션 (Type Promotion):** 서로 다른 타입(예: int + float)을 연산하면 PyTorch가 오류 없이 자동으로 더 높은 정밀도인 `float32`로 상위 변환하여 연산합니다.

**[EN]**
* **Default Dtypes:**
  * Integers: `torch.int64` (Long Tensor)
  * Decimals: `torch.float32` (Float Tensor)
* **Best Practice for Deep Learning:** Use `torch.float32` (Fast, accurate, standard on GPUs).
* **Convert using:** `torch.tensor(data, dtype=torch.float32)` or `tensor.float()`
* **Type Promotion:** Combining different types (e.g., int + float) automatically promotes the result to `float32` without throwing errors.

## 3. Tensor Creation & Reshaping (텐서 생성 및 차원 변환)

**[KR]**
* **텐서 생성 방법 (Creation Methods):**
  * Python 리스트 활용: `torch.tensor([1.0, 2.0])`
  * Numpy 배열 변환: `torch.from_numpy(arr)` (주의: 메모리를 공유하므로 한쪽을 바꾸면 함께 변경됨!)
  * 내장 생성 함수 (Built-in functions): `torch.zeros()`, `torch.ones()`, `torch.rand()`
* **단일 샘플 추론 시 차원 처리 (Handling Single-Sample Inference):**
  * 단일 입력 스칼라 값(예: 25.0)은 모델이 요구하는 배치 구조 `[1, 1]` 형태를 갖추지 못합니다.
  * `unsqueeze(dim)`: 지정한 위치(dim)에 크기가 1인 차원을 추가합니다 (예: 1차원 $\rightarrow$ 2차원 배치 형태).
  * `squeeze()`: 크기가 1인 모든 차원을 제거합니다.

**[EN]**
* **Creation Methods:**
  * From Python Lists: `torch.tensor([1.0, 2.0])`
  * From Numpy Arrays: `torch.from_numpy(arr)` (Note: Memory is shared between Numpy and PyTorch!).
  * Built-in functions: `torch.zeros()`, `torch.ones()`, `torch.rand()`
* **Handling Single-Sample Inference:**
  * Single input scalar (e.g., 25.0) lacks the required batch shape `[1, 1]`.
  * `unsqueeze(dim)`: Adds a dimension of size 1 (e.g., 1D $\rightarrow$ 2D batch shape).
  * `squeeze()`: Removes all dimensions of size 1.

## 4. Slicing & Extracting Values (슬라이싱 및 값 추출)

**[KR]**
* **인덱싱 및 슬라이싱 (Indexing & Slicing):** Python 표준 슬라이싱과 동일하게 작동합니다.
  * `tensor[0]`: 첫 번째 샘플 (First sample)
  * `tensor[:3]`: 처음 3개 샘플 (First 3 samples)
  * `tensor[:, 1]`: 다차원 텐서 요소 접근 (Accessing multi-dimensional elements)
* **Python 스칼라 값 추출 (Extracting Python Scalars):**
  * `tensor.item()`: 단 하나의 원소를 가진 텐서를 Python의 숫자(float/int)로 변환합니다.
  * **주의 (Warning):** 원소가 2개 이상 포함된 텐서에 `item()`을 호출하면 `ValueError` 에러가 발생합니다.

**[EN]**
* **Indexing & Slicing:** Standard Python indexing applies.
  * `tensor[0]`: First sample
  * `tensor[:3]`: First 3 samples
  * `tensor[:, 1]`: Accessing multi-dimensional elements
* **Extracting Python Scalars:**
  * `tensor.item()`: converts a single-element tensor into a Python float/int.
  * **Warning:** Calling `item()` on tensors with more than 1 element raises a `ValueError`.
