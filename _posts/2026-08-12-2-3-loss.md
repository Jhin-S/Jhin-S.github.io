## 1. The 3-Step Training Cycle (3단계 학습 순서)

**[KR]**
* **3단계 패턴 (3-Step Pattern):**
  1) **측정 (Measure - Loss Function):** 모델의 예측이 얼마나 틀렸는지를 하나의 단일 수치(점수)로 측정합니다.
  2) **진단 (Diagnose - `loss.backward()`):** 각 가중치가 전체 오차에 얼마나 기여했는지를 평가합니다 (기울기 계산).
  3) **수정 (Update - `optimizer.step()`):** 진단 점수에 따라 파라미터 가중치를 업데이트합니다.

**[EN]**
* **3-Step Pattern:**
  1) **Measure (Loss Function):** Calculates how wrong predictions are as a single numeric score.
  2) **Diagnose (`loss.backward()`):** Evaluates how much each weight contributed to the total error.
  3) **Update (`optimizer.step()`):** Adjusts parameter weights according to diagnostic scores.

## 2. Regression Loss - Mean Squared Error (회귀 손실 - MSE)

**[KR]**
* **단순 오차 평균의 한계 (Why raw errors fail):**
  * 예시: 1번 예측 오차(+2), 2번 예측 오차(-2)
  * 단순 평균 (Raw Average): $\frac{+2 + (-2)}{2} = 0$ (두 번 모두 틀렸음에도 완벽한 예측처럼 보입니다!)
* **MSE가 효과적인 이유 (Why MSE works):**
  * **부호 제거 (Squaring removes negative signs):** 제곱을 통해 음수 부호를 없애 모든 오차가 손실 값에 긍정적으로(positively) 반영됩니다.
  * **큰 오차에 대한 강력한 벌점 (Penalizes large errors heavily):** 1분 틀린 오차는 $1$의 벌점을 받지만, 10분 틀린 오차는 제곱되어 $100$의 벌점을 받습니다.

**[EN]**
* **Why raw errors fail:**
  * Example: Prediction 1 error (+2), Prediction 2 error (-2).
  * Raw Average: $\frac{+2 + (-2)}{2} = 0$ (Looks like perfect accuracy despite 2 mistakes!).
* **Why MSE works:**
  * **Squaring removes negative signs:** All errors contribute positively.
  * **Penalizes large errors heavily:** Being off by 10 minutes gives an error scale of $100$, whereas being off by 1 minute gives $1$.

## 3. Classification Loss - Cross Entropy Loss (분류 손실 - Cross-Entropy)

**[KR]**
* **확률 분포 형태 (Probability Distribution):**
  * 모델 출력은 총합 $100\%$인 10개의 확률 점수를 반환합니다 (예: 3일 확률 $70\%$, 2일 확률 $8\%$).
* **작동 방식 (Behavior):**
  * 확신에 찬 오답에 큰 벌점을 부여합니다 (Punishes overconfident wrong predictions).
  * **손실 극대화 (High Loss):** 정답이 3인데 모델이 $95\%$ 확률로 7이라고 자만하며 틀린 경우.
  * **손실 상대적 감소 (Lower Loss):** 정답이 3인데 모델이 $55\%$ 확률로 7이라고 애매하게 틀린 경우.

**[EN]**
* **Probability Distribution:**
  * Output produces 10 probability scores adding up to $100\%$ (e.g., $70\%$ sure it's 3, $8\%$ sure it's 2).
* **Behavior:**
  * Punishes overconfident wrong predictions.
  * **High Loss:** Model is $95\%$ confident it's a 7, but the true label is 3.
  * **Lower Loss:** Model is $55\%$ confident it's a 7, and true label is 3 (Wrong, but less confident).

## 4. Loss Function Selection Rules (손실 함수 선택 및 주의사항)

**[KR]**
* **선택 요약 (Selection Summary):**
  * **연속형 수치 예측** (거리, 가격, 온도 등): `nn.MSELoss()` 사용.
  * **범주/클래스 예측** (숫자, 동물, 카테고리 등): `nn.CrossEntropyLoss()` 사용.
* **주요 주의 사항 (Important Rules):**
  * 회귀용/분류용 손실 함수를 서로 교차하여 혼용하지 말 것.
  * MSE 손실 값과 Cross-Entropy 손실 값의 절대적인 숫자(raw loss values)를 직접 비교하지 말 것 (원리 및 스케일이 완전히 다름).
  * 학습 과정에서 손실 값이 지속적으로 감소하는지에만 집중할 것.

**[EN]**
* **Selection Summary:**
  * **Predicting Numbers** (Distance, Price, Temp): Use `nn.MSELoss()`.
  * **Predicting Categories** (Digit, Animal, Class): Use `nn.CrossEntropyLoss()`.
* **Important Rules:**
  * Do NOT mix regression/classification loss functions.
  * Do NOT compare raw loss values between MSE and Cross-Entropy (different scales).
  * Focus on whether the loss decreases continuously during training.
