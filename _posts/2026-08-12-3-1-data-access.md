## 1. The 3 Core Methods of Custom Dataset (커스텀 데이터셋의 3대 필수 메서드)

**[KR]**
* **구조적 규약 (Structure Contract):**
  * `__init__()`: 파일 경로와 메타데이터를 설정합니다. 메모리에 원시 이미지를 직접 로드하지 않습니다 (지연 로딩 원칙, Lazy Loading).
  * `__len__()`: 전체 샘플 수를 반환합니다.
  * `__getitem__(idx)`: 요청된 인덱스 `idx`에 해당하는 단일 이미지와 레이블 쌍을 개별 로드하여 반환합니다.

**[EN]**
* **Structure Contract:**
  * `__init__()`: Sets up file paths and metadata. Does not load raw images into memory (Lazy Loading).
  * `__len__()`: Returns total sample count.
  * `__getitem__(idx)`: Loads and returns the single image and label pair for the requested index `idx`.

## 2. Custom Dataset Implementation for Oxford Flowers (Oxford Flowers 커스텀 데이터셋 구현)

**[KR]**
* 파이썬 스크립트 및 `scipy.io`를 활용하여 MATLAB 파일(.mat) 구조의 레이블을 파싱하고 PyTorch 데이터셋으로 변환하는 과정입니다.

**[EN]**
* The process of parsing labels from MATLAB (.mat) files using `scipy.io` and converting them into a PyTorch dataset.

```python
import os 
import scipy.io 
from PIL import Image 
from torch.utils.data import Dataset 

class OxfordFlowerDataset(Dataset): 
    def __init__(self, img_dir, mat_file, transform=None): 
        self.img_dir = img_dir 
        self.transform = transform 
        
        # MATLAB 파일 파싱하여 레이블 추출
        mat_data = scipy.io.loadmat(mat_file) 
        raw_labels = mat_data['labels'][0] # 1~102 범위의 배열
        
        # PyTorch용 0-기반 인덱싱으로 보정 (1~102 -> 0~101)
        self.labels = [l - 1 for l in raw_labels] 

    def __len__(self): 
        return len(self.labels) 

    def __getitem__(self, idx): 
        # 파일명 1-기반 인덱싱 오차 보정 (image_00001.jpg는 1부터 시작, idx는 0부터 시작)
        file_idx = idx + 1 
        img_name = f"image_{file_idx:05d}.jpg" 
        img_path = os.path.join(self.img_dir, img_name) 
        
        # PIL 이용한 이미지 지연 로딩
        image = Image.open(img_path).convert('RGB') 
        label = self.labels[idx] 
        
        if self.transform: 
            image = self.transform(image) 
            
        return image, label 
```

## 3. Critical Debugging Lessons (핵심 디버깅 교훈)

**[KR]**
* **교훈 1: 레이블 인덱싱 오차 (Lesson 1: Off-by-one Label Indices)**
  * PyTorch `nn.CrossEntropyLoss()`는 레이블 범위를 $[0, N-1]$로 요구합니다. 파싱된 레이블의 최소/최대값을 항상 확인할 것.
* **교훈 2: 파일명 인덱싱 오차 (Lesson 2: Off-by-one Filename Indices)**
  * 파이썬 인덱스 (`idx = 0`)와 실제 파일명 (`image_00001.jpg`) 간의 번호 불일치를 주의해야 합니다.
  * 전체 학습 루프를 돌리기 전, 항상 `dataset[0]`을 단독 호출하여 `FileNotFoundError` 유무를 사전 테스트할 것.

**[EN]**
* **Lesson 1: Off-by-one Label Indices**
  * PyTorch `nn.CrossEntropyLoss()` requires labels in range $[0, N-1]$. Always verify min/max values of parsed labels.
* **Lesson 2: Off-by-one Filename Indices**
  * Dataset Indexing (`idx = 0`) vs File naming (`image_00001.jpg`).
  * Always test `dataset[0]` early before launching training loops to catch `FileNotFoundError`.
